🏥 Hospital Patient Data Analysis & Healthcare Analytics

📌 About the Project

This is a Python-based data analytics project focused on generating and analyzing 1,000 synthetic hospital patient records to identify meaningful patterns and insights in healthcare data.

🎯 Project Objectives

- Analyze hospital patient records.
- Understand disease and department distribution.
- Analyze treatment costs and recovery rates.
- Identify patterns through data visualization.
- Generate meaningful healthcare insights.

🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly

📊 Key Features

- Patient Data Generation
- Data Quality Checks
- Statistical Analysis
- Department-wise Analysis
- Disease-wise Analysis
- Doctor-wise Analysis
- Gender-wise Analysis
- Treatment Cost Analysis
- Recovery Rate Analysis
- Data Visualization
- Project Insights

📈 Key Project Findings

- Total Patient Records: 1,000
- Average Patient Age: 44.27 years
- Most Common Disease: Diabetes
- Most Visited Department: Pediatrics
- Average Treatment Cost: ₹1,04,442.32
- Average Recovery Rate: 79.16%
- Average Hospital Stay: 15.75 days

📁 Project Structure

- "Hospital_Analysis.ipynb" – Main analysis notebook
- "visualizations/" – Generated charts and graphs
- "README.md" – Project documentation
- "requirements.txt" – Project dependencies
